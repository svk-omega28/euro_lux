## 🌟 О сервисе

Euro Lux - это специализированная платформа для рекрутинга сотрудников из Украины, Беларуси и других стран для работы в Польше. Мы соединяем проверенных работодателей с квалифицированными кандидатами.

**Ключевые преимущества:**
✅ Прямые контракты с польскими компаниями  
✅ Полное юридическое сопровождение  
✅ Поддержка на всех этапах трудоустройства  
✅ База проверенных вакансий  

## 🚀 Наши услуги

| Услуга | Описание |
|--------|----------|
| **Подбор персонала** | Поиск сотрудников по требованиям работодателя |
| **Верификация кандидатов** | Проверка документов и квалификации |
| **Организация собеседований** | Онлайн и оффлайн встречи с работодателями |
| **Помощь с релокацией** | Поддержка в оформлении документов и переезде |
